# Для ИИ

Перед первой правкой задачи прочитай целиком:

1. `docs/constitution.md` — законы.
2. `docs/architecture.md` — кто за что отвечает и куда класть изменение.

Правила игрока и числа баланса — в `README.md`. Их читают, когда правка видна игроку или меняет число, которое README уже называет.

Дока обновляется той же правкой, которая её состарила. Какой файл трогать, сказано в `docs/constitution.md`.
